How to export from your calendar
G
Google Calendar
Settings (gear icon) → Settings → Import & Export → Export. Download the zip, extract the .ics file, then upload above.
O
Outlook / Microsoft 365
Go to Outlook Calendar → Settings → View all Outlook settings → Calendar → Shared calendars. Copy the link ending in .ics and paste in the URL field above.
A
Apple Calendar (iPhone / Mac)
On Mac: File → Export → Export as .ics. On iPhone: use a third-party app like "ICSx5" or export via iCloud.com on desktop.
